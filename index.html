How A* Works

Three scores, one decision

g(n) is the best known number of moves from the start. h(n) estimates the moves remaining. f(n) is their sum.

  1. Add the start to the frontier with g = 0.
  2. Remove the frontier node with the lowest f.
  3. If it is the destination, follow parent links to recover the path.
  4. Explore its walkable neighbors. If a cheaper route is found, update their scores and parent; add them to the frontier.
  5. Repeat. An empty frontier means no path exists.

Readable pseudocode

g[start] = 0; frontier.add(start)
while frontier is not empty:
    current = frontier.removeLowestF()
    if current == destination:
        return reconstructParents(current)
    mark current explored
    for each walkable neighbor:
        tentative = g[current] + 1
        if tentative < g[neighbor]:
            parent[neighbor] = current
            g[neighbor] = tentative
            h[neighbor] = Manhattan(neighbor, destination)
            f[neighbor] = g[neighbor] + h[neighbor]
            frontier.addOrUpdate(neighbor)
return no path

Why Manhattan distance?

h = |row − goalRow| + |column − goalColumn|. Each move changes just one coordinate by one. Without walls, this is the exact distance. Walls can only make the route longer, so this heuristic never overestimates.

With unit costs and four-directional movement, Manhattan distance is consistent. A* can safely finalize an explored node and returns an optimal path when the destination is removed from the frontier.

When there is no path

Walls may disconnect the destination. A* finishes after exploring the reachable region and exhausting the frontier; it does not keep searching forever.

Presentation test checklist

Load an example above, then use Step or Run A*. Expected lengths count moves, not cells.

  • Empty board: 40 moves.
  • Wall with a gap: 40 moves, crossing the gap at (12, 12).
  • Blocked destination: “No path exists”; controls remain usable.
  • Close endpoints: 1 move.
  • Long detour: 60 moves.
  • Repeated run: Reset Path, then run again. Walls remain; results match.
